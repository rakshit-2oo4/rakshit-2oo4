### 📌 Featured Projects

#### 🎬 WebMax — OTT Video & Audio Streaming Platform
A full-scale streaming platform spanning web and React Native mobile on a shared backend.
- Subscription plans, content rental (Razorpay WebView flow), and purchase systems
- CBFC content rating pipeline across the entity/service/controller/frontend layers
- Secure REST APIs for auth, media delivery, and user/profile management
- Custom subtitle styling and premiere countdown overlays on web & mobile
- **Stack:** React, React Native, Node.js, PostgreSQL, Razorpay

#### 📈 DLS Group — Creator Campaign Management Platform
A creator monetization platform integrated with Instagram & TikTok.
- Campaign participation, reel tracking, referral system, and reward payouts
- Wallet system with PDF invoice generation (PDFKit) and Telegram bot integration
- Admin tooling for proposal management, CSV import/export, and bonus/coupon systems
- AI support chatbot (Gemini API, function-calling, JWT-scoped) with human-handoff fallback
- **Stack:** React, TypeScript, Node.js/Express, PostgreSQL

#### 🏢 Sky HRMS — Multi-Tenant HR Management System
A multi-tenant Core HR + CRM system built with NestJS and Prisma.
- Organization-scoped data isolation via a custom `OrganizationGuard` + Prisma client extension pattern
- Modules for employees, attendance, leave, payroll, invoices, offer letters, and grievances
- Role-based access control (Admin/Manager/HR/Employee) enforced across all endpoints
- Auto-generated, S3-hosted PDF invoices and offer letters
- **Stack:** NestJS, Prisma, PostgreSQL, React, Redux Toolkit (RTK Query), AWS S3
